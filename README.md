# NewPro - Digital Marketing & Dedicated Rich Content Agency

NewPro is a premier B2B rich content agency based in Nijmegen, Netherlands. We create high-converting video formats, studio podcasts, and thought leadership articles with dedicated on-camera actors and a full in-house production crew.

## 🚀 Pages & Structure

- **[Home (`index.html`)](index.html)**: Hero showcase, 3 core pillars (Video, Podcast, Blogs), video portfolio marquee, pricing tiers, workflow roadmap, and trilingual support.
- **[Over Ons (`over-ons.html`)](over-ons.html)**: Our philosophy ("van merk tot mens, van mens tot mens"), team leadership, and Studio Nijmegen broadcast facilities.
- **[Abonnementen (`abonnementen.html`)](abonnementen.html)**: Transparent monthly subscriptions (€949, €1.799, €3.399), ROI calculator, feature matrix table, and interactive quote request form.
- **[Acteurs & Presentatoren (`acteurs.html`)](acteurs.html)**: Dedicated talent roster with interactive category filters, video case studies with modal player, casting roadmap, executive coaching, and talent request form.
- **[Kennisbank & Blogs (`blogs.html`)](blogs.html)**: B2B video marketing playbooks, featured cornerstone article, interactive reading modal, and newsletter subscription.
- **[Contact (`contact.html`)](contact.html)**: Studio Nijmegen direct channels (WhatsApp, Phone, Email), interactive 20-minute meeting scheduler, team directory, and Google Maps directions.

## 🎨 Features & Design System

- **Clean Vanilla Architecture**: Pure semantic HTML5, modern CSS3 variables, and vanilla JavaScript (zero heavy framework dependencies).
- **Trilingual Localization**: Instant switching between Dutch (`NL`), English (`EN`), and Indonesian (`ID`).
- **Dark & Light Mode**: Default clean Light Mode with high-contrast Dark Mode toggle.
- **100% Symmetrical Layouts**: Carefully balanced typography and grids designed for enterprise trust.

## 🌐 Deploy on GitHub Pages

1. Push this repository to your GitHub account (`git push -u origin main`).
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Under **Branch**, select `main` and root (`/`), then click **Save**.
4. Your site will be live at `https://<your-username>.github.io/<repository-name>/`.
